# 🛒 RetailHub

سامانه **RetailHub** یک راهکار بک‌اند مدرن، پایدار و ماژولار مبتنی بر **Django** و **Django REST Framework (DRF)** است که برای مدیریت فروشگاه‌ها، باغ‌تالارها، مراکز فروش نهال و گل‌وگیاه و کسب‌وکارهای زنجیره‌ای طراحی شده است.

این سیستم شامل احراز هویت اختصاصی بدون وضعیت (Stateless)، مدیریت مالی و تراکنش‌های اتمیک، مدیریت چک‌های صیادی، کنترل هزینه‌ها، ثبت ضایعات، چک‌لیست‌های پویا و سیستم پیشرفته مدیریت سطوح دسترسی است.

---

## ✨ ویژگی‌های کلیدی

### 🔑 احراز هویت اختصاصی بدون وضعیت (Custom Stateless Authentication)

* استفاده از `TimestampSigner`
* تولید Access Token و Refresh Token با کارایی بالا
* همگام‌سازی زنده نقش‌ها و وضعیت کاربران
* بدون نیاز به ذخیره توکن در دیتابیس

### 🛡️ مدیریت سطوح دسترسی (RBAC)

نقش‌های پشتیبانی‌شده:

* `ADMIN` — مدیر سیستم
* `CASHIER` — صندوق‌دار
* `USER` — کارمند عادی

قابلیت کنترل دسترسی به داده‌های شخصی هر کاربر و سطوح مختلف مدیریتی.

### 💼 تراکنش‌های مالی اتمیک

* ثبت همزمان فاکتور فروش
* پرداخت‌های ترکیبی
* مدیریت بیعانه‌ها
* مدیریت چک‌ها
* استفاده از `select_for_update` جهت جلوگیری از مشکلات همزمانی

### 📝 مدیریت چک و هزینه‌ها

* ثبت چک‌های دریافتی
* خرج کردن چک‌ها (Endorsement)
* رهگیری کامل زنجیره انتقال چک
* مدیریت هزینه‌های فروشگاه

### 📊 مدیریت خروج کالا و ضایعات

* ثبت مرجوعی کالا
* ثبت خرابی‌ها
* ثبت مصرف داخلی کالا
* گزارش‌گیری از ضایعات

### ✅ سیستم تسک و چک‌لیست

* ایجاد چک‌لیست‌های روزانه
* ثبت وضعیت انجام وظایف
* ثبت خودکار زمان و کاربر انجام‌دهنده
* محدودسازی دسترسی کاربران عادی

# 🚀 راه‌اندازی پروژه

## روش اول: Docker (پیشنهادی)

ابتدا اطمینان حاصل کنید که Docker و Docker Compose نصب شده‌اند.

### 1. تنظیم فایل `.env`

```env
SECRET_KEY=your-super-secret-key-for-retailhub-2026
DEBUG=True
ALLOWED_HOSTS=*
```

### 2. اجرای پروژه

```bash
docker-compose up --build -d
```

### 3. ساخت دیتابیس و داده‌های اولیه

```bash
docker-compose exec web python manage.py seed
```

این دستور:

* Migrationها را اجرا می‌کند.
* کاربران تستی را ایجاد می‌کند.
* داده‌های اولیه سیستم را وارد می‌کند.

---

## روش دوم: اجرای محلی

### 1. ساخت محیط مجازی

```bash
python -m venv venv
```

فعال‌سازی:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3. آماده‌سازی دیتابیس

```bash
python manage.py seed
```

### 4. اجرای سرور

```bash
python manage.py runserver
```

سرویس در آدرس زیر در دسترس خواهد بود:

```text
http://127.0.0.1:8000
```
