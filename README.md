🛒 سامانه RetailHub (بک‌اند جامع مدیریت خرده‌فروشی و امور مالی)

سامانه RetailHub یک راهکار بک‌اند مدرن، پایدار و ماژولار مبتنی بر فریم‌ورک Django و Django REST Framework (DRF) است که برای مدیریت فروشگاه‌ها، باغ‌ تالارها، مراکز فروش نهال و گل‌و‌گیاه، و کسب‌وکارهای زنجیره‌ای طراحی شده است.

این سیستم مجهز به سیستم احراز هویت اختصاصی بدون وضعیت (Stateless)، تراکنش‌های مالی اتمیک، سیستم پیشرفته مدیریت چک‌های صیادی و خرج‌شده، مدیریت هزینه‌ها، گزارش‌های ضایعات و چک‌لیست‌های پویا با سطوح دسترسی پیشرفته (Role-Based Access Control) است.

✨ ویژگی‌های برجسته پروژه

🔑 احراز هویت بدون وضعیت اختصاصی (Custom Stateless Auth): استفاده از TimestampSigner داخلی برای تولید توکن‌های Access و Refresh با کارایی فوق‌العاده بالا و بارگذاری مجدد زنده (Live Sync) نقش و وضعیت کاربر برای حداکثر امنیت.

🛡️ مدیریت سطوح دسترسی پویا (RBAC): پیاده‌سازی ۳ نقش کلیدی ADMIN (مدیر ارشد)، CASHIER (صندوق‌دار) و USER (پرسنل عادی) به همراه کنترل دسترسی دقیق به رکوردهای ثبت شده خود شخص.

💼 تراکنش‌های اتمیک پایدار (Atomic Database Transactions): ضمانت صحت داده‌ها در زمان ثبت همزمان فاکتور فروش، پرداخت‌های ترکیبی، مدیریت اقلام بیعانه و چک‌ها به همراه قفل همزمانی با استفاده از select_for_update بر روی داده‌های مشتری.

📝 مدیریت پیشرفته چک و هزینه‌ها: امکان خرج کردن چک‌های مشتریان بابت هزینه‌های جاری فروشگاه (Endorsement) و حفظ تاریخچه کامل زنجیره انتقال چک.

📊 خروج کالا و ضایعات: ثبت و ردیابی خروجی‌های کالا به دلایل مرجوعی، خرابی یا مصرف داخلی.

✅ چک‌لیست و کارهای روزانه (Tasks): سیستم هوشمند ثبت تسک‌ها که پرسنل عادی (USER) فقط می‌توانند وضعیت انجام آن را تغییر دهند و جزئیات سیستمی زمان و ثبت‌کننده به صورت خودکار ذخیره می‌شود.

🛠️ تکنولوژی‌های مورد استفاده

Python 3.11

Django 4.2+

Django REST Framework (DRF)

PostgreSQL / SQLite (پشتیبانی هوشمند از هر دو دیتابیس از طریق متغیرهای محیطی)

Gunicorn (وب‌سرور پایدار برای محیط پروداکشن)

🚀 راهنمای سریع راه‌اندازی و اجرا

پروژه به دو روش سنتی (محیط مجازی پایتون) و مدرن (داکر) قابل اجرا است.

روش اول: راه‌اندازی با Docker (توصیه شده)

قبل از شروع، مطمئن شوید Docker و Docker Compose روی سیستم شما نصب هستند.

۱. فایل متغیرهای محیطی (.env) را در مسیر اصلی پروژه بررسی و تنظیم کنید:

SECRET_KEY=your-super-secret-key-for-retailhub-2026
DEBUG=True
ALLOWED_HOSTS=*


۲. کانتینرها را بیلد کرده و روشن کنید:

docker-compose up --build -d


۳. دیتابیس را مهاجرت داده (Migrate) و داده‌های اولیه تستی را با یک دستور وارد کنید:

docker-compose exec web python manage.py seed


این دستور تمام جداول را ساخته و اکانت‌های تستی و ادمین را به صورت خودکار ایجاد می‌کند.

روش دوم: راه‌اندازی سنتی (محیط محلی)

اگر می‌خواهید پروژه را بدون داکر روی سیستم خود توسعه دهید:

۱. یک محیط مجازی بسازید و آن را فعال کنید:

python -m venv venv

# ویندوز:
venv\Scripts\activate

# مک و لینوکس:
source venv/bin/activate


۲. وابستگی‌ها را نصب کنید:

pip install -r requirements.txt


۳. دیتابیس را بسازید و داده‌های اولیه را لود کنید:

python manage.py seed


۴. سرور توسعه جنگو را روشن کنید:

python manage.py runserver


اکنون سرویس در آدرس http://127.0.0.1:8000 در دسترس است.

📂 ساختار پوشه‌بندی پروژه

RetailHub/
│
├── core/                # اپلیکیشن اصلی سیستم
│   ├── authentication.py # سرویس تولید توکن و لایه احراز هویت بدون وضعیت
│   ├── models.py         # مدل‌های دیتابیس (فروش، چک، هزینه، کاربر و...)
│   ├── permissions.py    # کنترل دقیق دسترسی نقش‌ها
│   ├── serializers.py    # سریالایزرهای پیشرفته پایتون و منطق‌های تراکنشی
│   └── views.py          # ویوها و هندلرهای API endpoint
│
├── project/             # پوشه تنظیمات اصلی جنگو
│   ├── settings.py       # پیکربندی کلی پروژه، CORS و دیتابیس
│   ├── urls.py           # روتینگ اصلی پروژه
│   └── wsgi.py           # کانکتور وب‌سرور
│
├── Dockerfile           # داکرفایل بیلد محیط پایتون و پروژه
├── docker-compose.yml   # ارکستریشن کانتینرهای پروژه
├── requirements.txt     # نیازمندی‌های پکیج‌های پایتونی
└── manage.py            # ابزار مدیریت پروژه و دستور seed
